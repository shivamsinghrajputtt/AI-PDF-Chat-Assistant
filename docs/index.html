Why this project

Built as a real RAG system, not a prompt wrapper.

The application keeps retrieval, evidence filtering, answer generation and conversation memory as separate responsibilities, making the system easier to test and reason about.

Multi-document retrieval

Upload several PDFs and search them together through separate persistent ChromaDB collections.

Grounded answers

Only relevant retrieved chunks are passed to the answer engine, with document and page sources exposed to the user.

Safe fallback

If no useful context is retrieved or Ollama is unavailable, the deterministic extractive path still works without an API key.

Conversation memory

Follow-up questions use bounded contextual memory instead of an ever-growing chat history.

Quality evaluation

Hit Rate and MRR utilities make retrieval quality measurable and regression-testable.

Input validation

PDF uploads are validated and fingerprinted before indexing to avoid invalid or duplicate work.
